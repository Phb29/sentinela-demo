# sentinela-demo

API de pedidos (Spring Boot 4, Java 25) usada para demonstrar o [Code Sentinela](https://github.com/Phb29/code-sentinela).

A branch `main` tem código correto. Os pull requests deste repositório trazem **bugs plantados de propósito**
para o revisor encontrar. Não copie o código dos PRs como exemplo sem ler os comentários da revisão.
